Provenance

Where every passage came from, how it was cut up, and what turned it into a vector. A retrieval result is only as checkable as the record of how the index was built, and most of these details are the ones that silently change a recall figure.

Synthetic, and openly so.

No redistributable corpus of multi-revision service manuals with variant effectivity, serial ranges, supersession edges and parallel English/Turkish/Russian text exists — real ones are a manufacturer’s commercial property. This project generates its own from a committed seed and never describes the result as real-world data. Ground truth is construction metadata: the generator knows which revision superseded which and which questions have no supporting passage, because it built them that way.

What is not measured here

  • No live language model has run. The default answerer is extractive — it returns spans verbatim from the cited passage, so it structurally cannot emit a part number the evidence does not contain. The abstractive arm exists behind the same port and raises without a key. No cost, latency or quality figure is published for it, because none was ever measured.
  • No native speaker reviewed the Turkish or Russian text. It is synthetic parallel text whose ground truth is construction metadata. The multilingual figures are a measurement over generated text, not a human-validated benchmark, and no judge calibration was performed.
  • No managed cloud vector service was provisioned. The comparison runs a second backend in a local container.
