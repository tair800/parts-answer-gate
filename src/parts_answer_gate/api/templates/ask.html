Ask

A technician’s parts or procedure question, answered with a variant-correct, revision-correct citation — or refused. The two fields that change the answer are the machine and the date: a procedure correct for an XP-400 is wrong for an XP-400S, and the approved procedure on the date of an incident is not always the one approved today.

Why the gate decided that

Every signal below is computed before any text is generated, and not one of them is a model output. The decision to answer is deterministic; the model is only ever asked to phrase something the gate already permitted.

{% set s = answer.decision.signals %}
signalvaluewhat it rules on
top fused score{{ "%.4f"|format(s.top_fused_score) }} the cheapest evidence that nothing relevant was found
supporting chunks{{ s.supporting_chunks }} one lucky passage is not corroboration
term coverage{{ "%.4f"|format(s.term_coverage) }} a passage about the right product but the wrong attribute scores well and supports nothing
variant agreement{{ "yes" if s.variant_agreement else "NO" }} evidence from two machines is a conflict, not a consensus
