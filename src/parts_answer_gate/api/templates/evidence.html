Where the failures come from

A wrong answer whose supporting passage was never retrieved is a retrieval failure; one where the passage was retrieved and the answer still wrong is a generation failure; one the gate should have refused is a gate failure. Reporting a single accuracy number hides which of the three to go and fix.

A vacuous pass is not a pass. G reports a wrong-answer rate of zero, and the zero is worth nothing: the effectivity predicate excludes revision- and variant-incorrect passages upstream of the gate, so no answer this system can give is capable of being wrong in either sense. G cannot distinguish this system from a broken one. It is reported as it measured, with this note attached.
